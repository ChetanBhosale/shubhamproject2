# Tozumlo Test

Emotional wellness companion for everyday mental health. An interactive mobile app prototype rendered as a polished iPhone 16 Pro mockup, with a navigable flow across nine screens.

## Stack

- Next.js 16 (App Router, Turbopack)
- React 19, TypeScript
- Tailwind CSS v4
- Framer Motion (animations)
- shadcn/ui primitives
- lucide-react icons

## Screens

Home · Journal · AI chat (Lumi) · Breathing · You / Profile  
Pushed: Routine · Mood analytics · Sleep recovery · Calm space · Circles

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm run start
```

## Design system

- Cream surface (`#F7F3EE`) with thick rounded black borders and hard offset shadows
- Pastel cards: peach, lavender, butter, mint, rose, blue
- Brand accents used sparingly: Sage `#B9CDBE`, Mint Teal `#57A999`, Warm Orange `#F69A4A`, Muted Lavender `#756187`, Deep Ocean `#003F54`, Soft Surface `#ECECEC`
- Spring-based motion with staggered entrance and shared layout transitions on the bottom navbar
